# UCNA Training Simulator

Offline-capable Bridge Command / EmptyEpsilon training academy. This is an unofficial, non-commercial community fan project, not endorsed by the game developers.

**Online Academy:** https://w1face.github.io/ucna-training-simulator/

**Offline edition:** Choose **Download Offline Academy (v1.2)** on the Academy homepage. That HTML contains the four existing trainers and the artwork, and does not require an internet connection.

## Training modules

- Radar Scanning
- Radar Icon Recognition
- Radar Signature Analysis
- Hacking & System Disruption

## Updating the Academy

The online training launcher is `index.html`. Individual trainer implementations remain separate files under `trainers/`, so modules can be replaced independently.

Academy artwork is in `assets/`; official-role-inspired navigation symbols are in `assets/icons/`. For an offline release, regenerate the bundled HTML in `downloads/`.

GitHub Pages publishes the `main` branch from the repository root. Browser-stored results remain local to each officer's browser and do not automatically sync between online and offline editions.
