# UCNA Training Simulator

A standalone, browser-based Bridge Command / EmptyEpsilon training academy. Unofficial community project, not endorsed by the game developers.

## Publishing the Academy

Upload the *contents* of `UCNA_GitHub_Pages_Ready_v1.1.zip` to the root of this repository, preserving its `trainers/`, `assets/`, and `downloads/` directories. The archive includes `index.html`, four trainer modules, and a standalone offline download.

To enable GitHub Pages: Settings > Pages > Build and deployment > Deploy from a branch > `main` > `/(root)` > Save.

Once published, the online Academy will be at https://w1face.github.io/ucna-training-simulator/.

For routine updates, maintain separate trainer modules in this repository and refresh the offline HTML download when issuing a new release.
